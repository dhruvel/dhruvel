## Projects

| Project | What it does |
| --- | --- |
| **[rtabmap_ros2_ws](https://github.com/dhruvel/rtabmap_ros2_ws)** | Real-time SLAM on ROS 2 Jazzy fusing an LDROBOT D500 LiDAR and an ASCAM HP60C RGB-D camera with RTAB-Map. 20 Hz on 640×480, with a sensor health monitor that catches failures in under 5 s. |
| **[Blockchain-DNS](https://github.com/dhruvel/Blockchain-DNS)** | A DNS resolver backed by an Ethereum smart contract instead of upstream nameservers, closing off cache poisoning. Solidity, web3.py, Sepolia. |
| **[Breathalyzer-CP320](https://github.com/dhruvel/Breathalyzer-CP320)** | Raspberry Pi breathalyzer: ultrasonic proximity sensing, MQ-3 alcohol sensor over an I²C ADC, and a servo needle readout. |
| **[CP322 ML Classification](https://github.com/dhruvel/CP322_ML_Classification-Project)** | KNN, logistic regression, AdaBoost, random forest and SVM classifiers implemented from scratch and compared on real datasets. |
